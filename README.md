# WinUninstaller

用来卸载 Windows 软件的小工具。

从 [Releases](https://github.com/Leskur/win-uninstaller/releases) 下载 `WinUninstaller` 开头的 exe，双击运行。系统会要求管理员权限。适用于 Windows 10 及以上的 64 位系统。

## 能做什么

- 查看已安装的桌面应用和微软商店应用，包括名称、大小、安装时间和发布者
- 按名称搜索
- 卸载选中的应用。卸载前会先确认
- 清理「残留」：卸载程序已经不在、只剩注册表记录的项目。清理只去掉这些记录，不删除文件
- 打开安装目录，或在注册表中定位该项

界面语言可以在「查看」菜单里切换中文和 English。

## 使用

在列表里选中一个应用，按 Delete，或右键选择「卸载」。名称后面带「残留」的项目会进入清理，而不是卸载。

按 F5 刷新列表。右上角可以搜索。
